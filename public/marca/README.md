# public/marca

Solte aqui logotipo, imagens e qualquer arquivo de marca (SVG, PNG, JPG...). É `public/`, então o
Next.js serve tudo daqui direto por URL — um arquivo `public/marca/logo.svg` fica acessível em
`/marca/logo.svg`, sem precisar de import nem de build.

Este README fica só para a pasta não sumir do git enquanto estiver vazia; pode conviver com os
arquivos ou ser apagado quando não fizer mais falta.
